# Vesti

Catálogo digital clean para lojas de roupas.

## Tecnologias
- HTML
- CSS
- JavaScript
- JSON

## Personalização
Edite `data/products.json` para alterar nome da loja, WhatsApp, Instagram e produtos. As imagens demonstrativas devem ser substituídas pelas fotos reais do cliente.

## Execução local
Como o projeto carrega o JSON usando `fetch()`, execute por um servidor local. No VS Code, a extensão Live Server é uma opção simples.
